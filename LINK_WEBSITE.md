## Deskripsi Website

Website profil SMA Negeri 3 Tegal merupakan aplikasi frontend yang dikembangkan menggunakan Next.js, JavaScript, App Router, dan Tailwind CSS.

Website ini menyediakan informasi mengenai profil sekolah, sejarah, visi dan misi, sambutan kepala sekolah, serta berbagai berita dan kegiatan SMA Negeri 3 Tegal.

Website dibuat tanpa menggunakan database, backend, API, maupun sistem autentikasi.
